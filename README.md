#  Madar Tech

The official landing page for "Madar Tech", an educational and training institution. The page is designed to present the institution's identity, services, and training programs in a modern and engaging way, bridging the gap between academic knowledge and practical application.

##  Features
- Responsive Design: Fully compatible with all screen sizes (mobile, tablet, and desktop) featuring a custom mobile navigation menu.
- Visual Animations: Smooth "Fade-in-up" scroll effects for cards and sections as the user scrolls down, providing a dynamic user experience.
- Interactive Hover Effects: Smooth interactions on buttons, service cards, and program cards when hovering with the mouse.
- Organized Structure: Clear page sections (Hero, About Us, Services, Training Programs, Why Us, and Contact).

##  Tech Stack
- HTML5 (Page structure).
- CSS3 (Styling, responsiveness, and animations).
- JavaScript (Scroll animations using IntersectionObserver and navbar logic).
- Bootstrap 5 RTL (To facilitate responsive design and support Arabic direction).
- Helper Libraries: Cairo Font (Google Fonts) and Font Awesome Icons.
